# 年度预算版接口

年度预算版已接入统一天然气预测服务，路由前缀为 `/annual-budget`。每年使用截至上一年 8 月的历史数据，预测预算年 1–12 月的一个平均价格，单位为元/立方米。五个模型均提供全变量和组合变量方案。接口返回的版本标记为“年度预算版”。

## 启动与认证

在 `experiment_reproduction` 目录运行服务。

```powershell
python -B -m service.app --host 127.0.0.1 --port 8000 --device cpu
```

接口文档位于 `http://127.0.0.1:8000/docs`，OpenAPI 描述位于 `/openapi.json`。年度接口复用服务的 `LNG_API_KEY` 配置。设置该环境变量后，请求需携带 `X-API-Key` 头。提交预测、训练和取消任务均支持 `Idempotency-Key`，同一键重复提交同一请求返回已保存的结果，同一键用于不同请求会返回 409。

## 路由

|方法|路径|用途|
|---|---|---|
|GET|`/annual-budget/models`|查看年度模型与可用权重|
|POST|`/annual-budget/predictions`|生成年度均价预测|
|GET|`/annual-budget/predictions`|查询年度预测历史|
|GET|`/annual-budget/predictions/{prediction_id}`|读取已保存的预测|
|GET|`/annual-budget/predictions/{prediction_id}/csv`|下载年度预测 CSV|
|POST|`/annual-budget/trainings`|提交年度训练任务|
|GET|`/annual-budget/trainings`|查询年度训练任务|
|GET|`/annual-budget/trainings/{training_id}`|查看进度与训练结果|
|POST|`/annual-budget/trainings/{training_id}/cancel`|取消年度训练任务|

## 生成预测

预测请求可指定预算年、模型、变量方案和数据版本。

```http
POST /annual-budget/predictions
Content-Type: application/json
Idempotency-Key: budget-2026-selected-joint

{
  "budget_year": 2026,
  "model": "joint_emaformer",
  "profile": "selected"
}
```

|字段|类型与默认值|含义|
|---|---|---|
|`budget_year`|整数，默认 2026|目标年度。数据必须覆盖该年前一年的 8 月|
|`model`|字符串，可省略|`all`、`lstm`、`emaformer`、`mofo`、`emmoformer`、`joint_emaformer`。使用随包权重时默认 `all`|
|`profile`|字符串，可省略|`all` 为全变量，`selected` 为组合变量，`both` 为两套变量。使用随包权重时默认 `both`|
|`data_version`|字符串，可省略|通过已有数据接口登记的数据版本|
|`training_id`|字符串，可省略|已成功完成的年度训练任务编号，用该任务的权重预测|

提交空对象 `{}` 时，服务使用 2026 年预算、五个模型和两套变量方案，返回三地区共 30 条价格。上述联合模型组合变量示例返回三条价格。2024、2025、2026 年均有随包权重。随包数据截至 2026 年 5 月，因此 2027 年预算须先补齐三地区至 2026 年 8 月的历史记录并完成训练。

提供 `training_id` 时，省略的 `model`、`profile` 和 `data_version` 会沿用该训练任务的选择；预算年仍须与任务一致，默认值为 2026。

响应中的 `prediction_id` 以 `apred_` 开头。`version` 为“年度预算版”，`budget_year`、`cutoff_month`、`target_start` 和 `target_end` 给出预算范围与数据截点。2026 年预算对应 `cutoff_month` 为 `2025-08`、`target_start` 为 `2026-01`、`target_end` 为 `2026-12`。

`predictions` 中每条记录包含 `model`、`profile`、`region`、`region_name`、`prediction`、`unit` 和 `n_train`。`prediction` 是年度算术均价，`n_train` 是该权重使用的训练样本数。`data_version` 标明实际选择的数据，`data_latest_observed_month` 是该版本最后观测月。即使数据含有截止 8 月之后的记录，年度输入也只使用截止月以前的观测。

`weight_source` 为 `bundled` 或 `training`，`training_id` 标明重训来源，`training_data_version` 标明任务训练时的数据版本（随包权重时为空）。`weights` 列出本次使用的模型、变量方案、地区和预算年。`detail_url` 与 `csv_url` 可直接用于查询和下载。

## 更新数据与提交训练

复用已有 `POST /datasets` 上传三地区处理后 XLSX，表单字段为 `shanghai_file`、`zhejiang_file`、`jiangsu_file`。首行字段名、第二行单位和月度日期格式沿用交付数据。获取响应中的 `dataset.data_version` 后，在年度训练请求中指定该值。

```http
POST /annual-budget/trainings
Content-Type: application/json
Idempotency-Key: budget-2026-lstm-training

{
  "budget_year": 2026,
  "model": "lstm",
  "profile": "selected",
  "name": "2026年度预算训练"
}
```

训练接受与预测相同的 `budget_year`、`model`、`profile` 和 `data_version`，另可填写 `name`。训练使用交付包中的固定变量、网络结构、优化器和轮数，按月建立历史样本。每条标签为预测起点后第 5–16 个月的实际价格均值，只有标签完整可用的样本参与训练。

提交成功返回 202 和以 `atrain_` 开头的 `training_id`。任务由统一队列安排独立工作进程执行，使用 `status_url` 查询。状态包括 `queued`、`running`、`cancel_requested`、`succeeded`、`failed`、`cancelled`、`interrupted`。`progress`、`stage` 和时间字段反映进度，`error` 保存失败原因。

成功任务的 `result` 包含 `configurations`、`weights_count`、`trained_at`、`prediction_id`、`predictions_url` 和 `csv_url`。训练结果保存为独立任务权重，原随包权重可继续使用。使用任务权重再次预测时，将成功任务的编号填入请求。

```http
POST /annual-budget/predictions
Content-Type: application/json

{
  "budget_year": 2026,
  "model": "lstm",
  "profile": "selected",
  "training_id": "atrain_替换为实际任务编号"
}
```

预测时所选年度、模型和变量方案须在训练任务保存的范围内。取消任务使用 `POST /annual-budget/trainings/{training_id}/cancel`，请求体为 `{}`。排队任务可以立即取消，运行任务会进入取消流程。任务和预测记录会持久保存，服务重启后仍可查询已保存结果。

## 错误响应

错误结构沿用统一服务，包含 `error`、`message`、`request_id` 和 `details`，响应头携带 `X-Request-ID`。

|HTTP 状态|典型情况|
|---|---|
|401|API 密钥缺失或错误|
|404|数据版本、训练任务或预测编号不存在|
|409|所选年度权重尚未提供、训练尚未成功、幂等键冲突或任务状态不允许操作|
|422|模型、变量方案或年份不合法，数据未覆盖预算年前一年 8 月，或请求超出重训配置范围|
|429|统一训练队列已满|

数据不足时返回 `INVALID_DATA`，缺少年度权重时返回 `ANNUAL_WEIGHTS_UNAVAILABLE`。调用方可依据 `request_id` 对照服务日志定位具体原因。

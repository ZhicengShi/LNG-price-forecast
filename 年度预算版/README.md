# 年度预算版

本目录提供上海、浙江、江苏的下一年度天然气平均价格预测，包含 LSTM、EMAformer、MoFo、EMMoFormer 和联合 EMAformer 五个模型。每个模型均提供全变量和组合变量方案，输出单位为元/立方米。将本目录完整复制到其他位置后，可以独立训练、预测和核验。

在完整交付目录中，年度预测和训练已接入共用 HTTP 服务，接口前缀为 `/annual-budget`。从上一级目录运行 `python -B -m service.app`，即可在 `/docs` 查看年度预算版接口。调用示例和数据版本流程见 [年度预算版接口说明](../service/年度预算版接口说明.md)。

## 预测与训练口径

每年 9 月编制预算，使用截至当年 8 月的数据。模型读取最近 6 个月的价格与特征，直接输出下一年 1–12 月的算术平均价格。例如 2025 年 9 月编制 2026 年预算，输入窗口为 2025 年 3–8 月，目标为 2026 年 1–12 月平均价格。

训练样本按月构造。对历史起点 t，输入 t−5 至 t 的 6 个月观测，训练标签为 t+5 至 t+16 的 12 个月实际价格均值。只有目标期已经完整观测的样本才进入训练。训练、缺失填充和标准化均限制在该预算编制时已知的历史内。相邻训练样本的目标期重叠 11 个月。

随包三张处理后数据表覆盖 2015 年 1 月至 2026 年 5 月。2026 年预算使用 2025 年 8 月起点，每地区对应 107 个训练样本。默认预测预算年为 2026。2027 年预算需要三地数据更新至 2026 年 8 月，并重新训练该预算年的权重。

单地区全变量输入数依次为上海 23、浙江 20、江苏 21，组合变量为 4、3、5。联合模型分别使用 34、12 个打包通道。固定字段与顺序见 `configs/models.json`。

## 安装与运行

使用 Python 3.11 或兼容环境。依赖见 `requirements.txt`，本机核验使用 Python 3.11、PyTorch 2.14.0+cu130。CPU 可运行，原实验使用 CUDA。

在本目录运行以下命令。

```powershell
python -m pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cu130
python -B predict.py --budget-year 2026 --device auto
python -B verify.py --device auto
python -B -m unittest discover -s tests -v
```

默认生成五个模型、两套变量方案、三地区共 30 条预测，保存到 `outputs/年度预算预测_2026.csv`。`predicted` 为年度均价，`cutoff_month` 为数据截止月，`target_start` 和 `target_end` 为预算覆盖期。

`outputs/` 用于保存运行结果，其内容可以随预测更新，交付完整性核验仅检查固定文件。

只运行联合模型组合变量方案，可执行以下命令，输出三地区各一个均价。

```powershell
python -B predict.py --budget-year 2026 --model joint_emaformer --profile selected --device cpu
```

`--model` 支持 `all`、`lstm`、`emaformer`、`mofo`、`emmoformer`、`joint_emaformer`。`--profile` 支持 `all`（全变量）、`selected`（组合变量）、`both`（两套）。`--data-dir` 指定三地区数据文件夹，`--weights-dir` 指定权重根目录，`--output` 指定结果 CSV。

## 更新数据与重新训练

数据表首行为字段名，第二行为单位，其后为升序连续月度观测。年月使用 `YYYY-MM` 文本，价格使用元/立方米，进口量使用吨。追加月份时保留既有列名、单位和固定变量。三地区的全国公共变量采用同一数据版本。

以下命令使用随包数据重新训练 2026 年预算，并将结果保存在单独目录。

```powershell
python -B train.py --budget-year 2026 --weights-dir outputs/重训权重 --output outputs/重训年度预测_2026.csv --device auto
python -B predict.py --budget-year 2026 --weights-dir outputs/重训权重 --output outputs/重载年度预测_2026.csv --device auto
```

当三地数据均更新至 2026 年 8 月后，可以把上述命令中的预算年改为 2027，并使用 `--data-dir` 指定更新后的数据目录。训练仅使用截至预算年前一年 8 月的记录。每个预算年都有对应权重，预测入口校验权重年份与截止月。

训练采用配置中保存的网络结构、学习率、轮数和种子。年度标签损失为标准化均价的均方误差。LSTM、EMAformer、MoFo 使用既有固定配置，EMMoFormer 和联合 EMAformer 使用年度实验开发期预选的配置。重训结果会受到设备和库版本影响。

## 评价范围

`reference/年度预算逐年预测.csv` 保存 2020–2026 年的 210 条年度预测，其中 2020–2025 年共 180 条有完整实际均价。2026 年全年实际均价留空。MAPE 为每地区六个预算年 APE 的算术平均，平均精度得分为 100 减 MAPE。

2020–2022 年参与开发选参，2023 年为补充回放，2024–2025 年为复核。历史结果为回顾性评价，部分原变量方案及架构参数在历史开发中已使用至 2024 年的数据。2020–2023 年的指标由保存的逐年预测记录复核，配套可重载权重覆盖 2024–2026 年。`verify.py` 针对随包基准数据与权重做一致性检查，更新数据后可通过训练和预测入口生成新的年度结果。

## 本次交付核验

本次重载 78 份权重，核对 90 条预测、210 条历史记录和 30 组指标。CUDA 预测与原始记录最大差小于 5×10⁻¹¹ 元/立方米。CPU 最大差约为 0.000075 元/立方米，来自设备数值计算差异，核验容差设为 0.0001 元/立方米。CUDA 核验容差为 10⁻⁸ 元/立方米。

另以固定配置重新训练全部 26 份 2026 年预算权重，所有参数张量、预处理统计量和样本起点均与随包权重完全一致。具体核验记录保存在 `reports/`。依赖已在现有算法环境验证。
